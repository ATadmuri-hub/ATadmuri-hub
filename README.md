## 📊 Featured projects

**[Airbnb Superhost & Price Prediction](https://github.com/ATadmuri-hub/Airbnb-Superhost-Price-Prediction)**
21 supervised learning models (13 classification, 8 regression) on 50,000+ listings across Madrid,
Barcelona, and Amsterdam. SHAP, calibration, bootstrap CIs, counterfactual analysis. R + Python.

**[AI Economic Vulnerability Index](https://github.com/ATadmuri-hub/Project-Which-Countries-Are-Most-Vulnerable-to-AI-Driven-Economic-Disruption-)**
PCA + three clustering methods (K-Means, hierarchical, Gaussian Mixture) with ARI validation to
rank ~200 countries by exposure and resilience to AI-driven disruption. Validated against the
Oxford AI Readiness Index.

**[Madrid Housing Market Analysis](https://github.com/ATadmuri-hub/Madrid-Housing-Market-Analysis)**
12-phase real-estate analytics framework on 11,826 listings: mispricing detection, district-level
forecasting, portfolio intelligence, and motivated-seller classification. Best model XGBoost
(R² = 0.74) in R / Quarto.

**[Spanish Immigration Rhetoric & Government Popularity](https://github.com/ATadmuri-hub/Data-Harvesting-uc3m-2026)**
Reproducible R harvesting pipeline (Wayback CDX API, rvest, httr2) building a 28-month panel.
ARIMA forecasting, Monte Carlo simulation (n=5,000) for D'Hondt seat projection, and interrupted
time-series analysis.

**[IKEA Price & Discount Prediction](https://github.com/ATadmuri-hub/IKEA-Price-Prediction-Discount-Classification)**
End-to-end ML pipeline on 3,694 products (R, tidymodels) using XGBoost, Elastic Net, Random Forest.

**[CIM Model — Migrant Integration through Community Sport](https://github.com/ATadmuri-hub/CIM-Model)**
Agent-based model (NetLogo) for my MSc thesis, testing community-sport program design before
implementation.

**[Small States Data Visualization](https://github.com/ATadmuri-hub/small-states-dataviz)**
Reproducible R/ggplot2 project on how population size relates to human development, governance,
and democratic freedoms (World Bank, UNDP, V-Dem).
